# Shopee 工作概述

主要负责 AI 基础设施与大模型服务平台的后端开发，工作覆盖 AIP、MaaS、AI Suite、计算集群管理及流量调度服务，参与需求分析、方案设计、开发测试、跨团队联调和线上问题排查。

## 一、平台与计算集群服务需求开发

### AIP 平台 v1.18～v1.21

负责 AIP 平台服务管理模块的需求迭代，完善服务创建、更新、查询和配置同步能力。开发 gRPC 限流重试、延迟直方图配置和模型备份检测等功能，打通平台配置与 Istio VirtualService、Pod 注解之间的同步链路。

优化模型与服务的关联关系及查询接口，将模型查询响应由超时改善至约 200 ms。支持服务与评估任务按状态检索，修复关联服务丢失、服务类型兼容和批量更新任务状态异常等问题，并完成存量数据迁移。

### MaaS 平台 v0.8.0

负责 MaaS 平台相关需求开发，完成 v0.8.0 接口设计、开发、自测和联调。建设服务 Overview，按项目和部署区域汇总 TUPM 配额、利用率及服务健康状态，支持服务明细筛选、排序和导出，完善关联服务状态与 Tag 同步。

完善 GPU 卡型选择、配额调整及扩缩容校验，根据模型部署配置、实际卡型和可用资源处理服务部署与 TUPM 配额变更；适配 vLLM Runtime 参数，支持服务路由策略配置与回显。

建设模型评估与压测模块，适配 vLLM、OneLLM、B200 GPU、自定义镜像及 Entrypoint，支持模型精度、输入长度和 TPS 等压测配置，提供任务状态、压测链接及输入输出 Token 吞吐量查询。采集线上请求日志并转换为压测数据集，通过定时任务上传至 S3，为模型评估提供真实请求数据。

完善服务可观测性与告警治理，补充模型、服务和 Tag 等告警维度，调整成功率统计规则，支持 TUPM 利用率与成功率的阈值、比较条件和持续时长配置。开发 AI 告警分析工具，接入服务信息与 Grafana 查询，并通过 Token 和操作白名单约束访问权限。

### AI Suite 平台与 LLM Gateway

负责模型广场、模型目录和用量统计相关接口开发，设计模型、API Provider 与供给路由的数据结构，迁移存量模型及白名单配置，完善模型可见性、调用权限和上下线状态管理，统一模型元信息并同步至模型广场。

持续接入和维护 GPT、Claude、Gemini、DeepSeek、GLM、Kimi 等模型及多模态服务，覆盖文本、Embedding、语音识别、图像、视频和音频能力。适配不同供应商的请求协议、响应结构、文件上传、工具调用及计价配置，支持 TokenHub 等供应商切换，处理模型字段透传和接口兼容问题。

统一模型访问控制，以模型与 Provider 为授权单元管理全量开放、项目灰度及禁用策略，收敛分散的白名单与权限校验逻辑。开发按日期、API Key、模型和供应商筛选的费用总览及明细查询，处理项目映射、Key 权限和金额精度，统一费用聚合口径。

建设 AQP 配额管理接口与运营前端，推进管理入口迁移，开发 Garena 配额管理及 IT 员工额度操作接口，支持用户状态、月度额度和用量查询等业务。维护模型计价，支持 DeepSeek 峰值计费和 Claude Fast Mode 等计价场景，排查配额、用量与计费链路问题。

### 计算集群管理服务

负责计算集群统一配置管理服务的后端设计与开发，提供集群创建、模块配置更新、配置查询、集群启用及列表管理等接口。按集群、模块和版本组织配置，记录状态、更新人和变更备注，支持集群配置的统一管理。

完成 Local Cluster Service v0.0.1 上线，为配置服务增加缓存模块，并结合 Kubernetes、Docker、Harbor 和 Argo CD 完成部署验证及运行问题排查。

## 二、流量调度服务路由算法开发

### 路由算法与推理优化

负责轮询、随机和前缀缓存等路由算法开发，通过统一路由接口封装实例选择逻辑，复用请求上下文和可用实例信息。前缀缓存路由结合历史请求前缀与实例负载，将相似请求优先分配至可复用缓存的实例，并在负载偏斜时优先均衡请求，减少重复 Prefill 计算。实验理论平均推理首 Token 时延（TTFT）降低约 13%。

### 动态配置与可观测性

开发服务与模型维度的批量动态配置接口，支持路由策略、日志开关、请求限制和单实例 TPM 等配置调整。通过服务配置持久化、SOC 注解下发和 Endpoint Informer 监听，将配置同步至 Smart Router，支持配置校验、目标合并及部分失败结果返回。

完善 Ext Proc 请求日志，增加 Service ID、Model ID 和流式请求响应体记录，支持服务维度日志级别调整，便于定位模型调用与路由链路问题。

### 网关扩展与性能验证

调研 Envoy Wasm、Higress 和 Dynamic Module 等网关扩展方案，验证将路由逻辑集成至网关以减少外部 gRPC 调用开销的可行性。开发 Go、Rust Wasm 插件 Demo，验证网络通信、Redis 适配及运行时兼容性。

使用 JMeter 和集群内客户端开展多并发、不同请求体大小的对比测试，分析平均延迟、P95 / P99、吞吐量、错误率及资源消耗，识别内存回收、运行时限制和场景间性能差异，为网关扩展方案选型提供实验依据。

## 技术栈

Go、GORM、Kubernetes、Docker、Harbor、Argo CD、Istio、Envoy、gRPC、Wasm、Prometheus、Grafana、Kafka、S3、vLLM、OneLLM、AIBrix。
